# FemLab Studio 使用教程

> 从零开始：用 FemLab Studio 完成第一个有限元分析 —— 2m 简支梁跨中集中力

本教程带你完整走一遍：**启动 → 建模 → 求解 → 看内力图 → 用 LLM 辅助**。

---

## 第 1 步：启动应用

**方式 A：运行安装包**（Windows）
1. 双击 `FemLab Studio_0.1.0_x64-setup.exe` 安装
2. 从开始菜单启动 **FemLab Studio**

**方式 B：开发运行**
```powershell
cd gui_tauri
npm install
npm run build
cd src-tauri
cargo tauri dev
```

启动后你会看到三栏界面：
- 左侧：项目管理
- 中间：画布（带网格）
- 右侧：工具栏 / 属性 / 结果 / LLM 助手

---

## 第 2 步：认识界面

```
┌─────────────────────────────────────────────────────────┐
│ FemLab  [LLM位置] [撤销] [重做] [重置视图] [求解 Ctrl+Enter]│
├──────────┬──────────────────────────┬────────────────────┤
│ +新建项目 │                          │  工具栏: 选择/节点/   │
│ 保存本地  │                          │   杆件/荷载/约束/删除 │
│ 导入本地  │      🎨 画布              │  属性面板            │
│          │      (点击/拖拽编辑)       │  求解结果            │
│ 项目列表  │                          │  LLM 建模助手        │
├──────────┴──────────────────────────┴────────────────────┤
│ 项目名 | 节点数·单元数·DOF | 模型有效性                     │
└─────────────────────────────────────────────────────────┘
```

**快捷键**：`Ctrl+Enter` 求解 · `Ctrl+Z/Y` 撤销重做 · `Delete` 删除选中

---

## 第 3 步：建模 — 2m 简支梁

1. 点击右侧工具栏 **「节点」**
2. 在画布上点三个点（约 (0,0) (1,0) (2,0) 位置，会自动吸附 0.1m 网格）
3. 点击工具栏 **「杆件」**，依次点 ①→②、②→③ 连接成两根杆
4. 点击工具栏 **「约束」**，点击左端节点（0号），在右侧勾选 `ux` `uy`（固定端）；点击右端节点（2号），勾选 `uy`（竖向滚轴）
5. 点击工具栏 **「荷载」**，点击中间节点（1号），方向 `y`，数值 `-10000`（向下 10kN）
6. 点击 **「求解」**（或 `Ctrl+Enter`）

> 💡 想清空重来？点左上「+ 新建项目」；误操作按 `Ctrl+Z`

---

## 第 4 步：查看结果

求解完成后，右侧「求解结果」面板显示：

| 区域 | 内容 |
|---|---|
| 统计卡片 | 节点 / 单元 / 自由 DOF 数 |
| **内力极值** | max\|N\| / max\|V\| / max\|M\| 及所在单元 |
| 位移表 | 各节点 ux / uy / rz |
| 杆端力表 | 各单元端部 N / V / M |
| 反力表 | 支座反力 Rx / Ry / Rz |

**画布可视化**（右下角切换条）：

| 模式 | 说明 |
|---|---|
| 原图 | 结构 + 节点位移标注（绿色小字，mm） |
| 轴力 N | 蓝色轴力图叠加 |
| 剪力 V | 橙色剪力图叠加 |
| 弯矩 M | 红色弯矩图叠加 |

变形图（红色虚线）在求解后自动叠加显示。

---

## 第 5 步：用 LLM 生成模型（可选）

1. 在 LLM 面板点 **「设置」**，填入：
   - `base_url`：如 `https://api.deepseek.com/v1`
   - `api_key`：你的密钥
   - `model`：如 `deepseek-chat`
2. 保存配置
3. 在输入框用自然语言描述结构，例如：

   > 建立一个 3x3 框架，每个构件 1000mm，每层水平荷载 10kN，截面随机定

4. 助手返回模型 → 点击 **「应用到画布 + 求解」**

> ⚠️ 注意：LLM 需联网且 API 可用；模型与当前画布相同时会提示，请重新描述。

---

## 第 6 步：保存 / 导入

- **保存到本地文件**：左侧栏按钮 → 选择位置，模型存为 `.json`
- **导入本地文件**：左侧栏按钮 → 选择 `.json` 模型文件加载
- **自动保存**：模型每次修改后自动保存到应用数据目录（`%APPDATA%\com.femlab.studio\projects\`）

---

## 第 7 步：调整布局

- **拖拽调宽**：左/右栏边缘有分隔条，拖动调整列宽（自动记住）
- **LLM 位置**：顶栏「LLM 移到底部 / LLM 移到右侧」切换

---

## 常见问题

**Q: 求解按钮点了没反应 / 提示调用后端失败？**
A: 确认 `femcli.exe` 存在（`build/bin/femcli.exe`，用 `cmake --build build` 构建）。应用会自动从 exe 所在目录向上查找。

**Q: 三栏没有分隔条？**
A: 分隔条在栏边缘，鼠标悬停会变蓝，拖动即可。

**Q: 右侧 LLM 面板被截断？**
A: 右侧面板支持滚动；也可以把 LLM 切到底部布局获得更大空间。

**Q: 导入的文件格式？**
A: 标准 JSON 模型文件（见 [模型 Schema](../FEM_MODEL_SCHEMA.md)），用「保存到本地文件」导出的即可直接导入。
