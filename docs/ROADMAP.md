# FemLab Studio 项目拓展规划（讨论稿）

> 定位：面向土木工程专业教学的结构力学交互式学习工具。
> 本文梳理未来拓展空间，按「教学主线 / 功能深化 / 技术升级」三维度。

## 〇、v0.3.1 已落地（2026-08-14，本次迭代起点）

- **精确内力图**：均布荷载剪力线性、弯矩抛物线（含反弯点）；变形图 Hermite 三次插值；显示选项卡含「挠度」
- **求解器修复 ×4**：momentOnPoint 节点弯矩崩溃、轴向荷载静默忽略、多荷载 FEF 覆盖、truss 节点 rz 垃圾值
- **建模体验**：节点 CAD 式坐标输入（`x,y` / mm 后缀）、杆上集中力点击定位、孤立节点诊断、5x5 刚框架教程
- **LLM Agent**：多轮工具调用 400 修复（Rust 消息字段丢失）、网格公式+模板提示、JSON 容错解析（实测 3x3 框架 5 轮完成）
- **质量体系**：独立参考求解器对照（13 案例）、渲染几何测试（26 项）、golden 回归、agent 容错单测
- **发版 v0.3.1**：CI 三平台 femcli + NSIS 安装包 + README 截图

**用户真实需求信号（来自本次迭代）**：参数化建模（5x5/3x3 框架两次提出）、CAD 式坐标输入、
内力图正确性关切（反弯点/剪力分布）、结果解读、诊断易用性。

## 一、教学主线（核心定位）

### 1. 结构力学实验库
- **预设实验**：每个结构力学知识点配一个可交互实验（静定判定、影响线、超静定弯矩分配）
- **参数化实验**：学生改一个参数（跨度/荷载/刚度比），实时看内力变化——**参数扫描动画**（连续改变 → 内力图动态更新）
- **影响线**：移动荷载沿结构移动，绘制影响线（教学难点，软件化价值高）

### 2. 作业与考核
- **作业模式**：老师导入题目（约束+荷载+答案），学生求解后自动判分
- **导出报告**：一键导出 PDF（模型图+内力图+结果表格+学生信息），直接交作业 ← 已有 PNG 导出，扩展为 PDF
- **题目生成器**：基于模板随机生成参数化题目（不同跨度/荷载组合）

### 3. 结构类型扩展（教学完整性）
- 目前：平面刚架/桁架（2D）
- **建议**：3D 空间桁架/刚架（教学上"空间结构"是必修）——大工程，需重写核心
- **可行中间态**：2.5D（平面内 + 面外屈曲概念演示，教学演示用近似）

## 二、功能深化（现有功能加强）

| 功能 | 现状 | 增强方向 |
|---|---|---|
| 荷载 | 集中/均布/线性/温度/支座位移 | 梯形分布、非节点荷载、动荷载(简谐)、地震/风荷载简化 |
| 结果可视化 | N/V/M 图 + 变形 | **叠加包络图**(多工况)、**动画**(振动模态)、应力云图(截面) |
| 求解能力 | 静力线弹性 | 几何非线性(大变形)、材料非线性(塑性铰)、模态分析、屈曲分析 |
| 截面库 | 自定义矩形 | 标准型钢库(H型钢/槽钢/角钢)、钢筋混凝土截面换算 |
| 材料库 | 自定义 | 混凝土/木材/铝等预设材料 + 强度验算(应力比) |

## 三、技术升级

### 1. 性能
- **WebAssembly 求解**：femcli 编译为 WASM，浏览器内直接求解（无后端进程），延迟 <10ms
- **大模型支持**：千节点级模型（当前 skyline 求解器已高效，但前端渲染需优化）

### 2. 协作与云
- **项目云同步**：登录 + 云端保存（教学场景：学生在家做，课堂演示）
- **分享链接**：一键分享模型+结果给同学/老师

### 3. 部署
- **Web 版**：Tauri 前端几乎可直接部署为 Web 应用（IPC 换成 WASM/HTTP）——覆盖「老师上课不想装软件」场景
- **移动端**：平板触控建模（教学演示）

## 四、推荐的「下一个里程碑」（性价比最高）

0. **参数化建模向导**（新增，需求信号最强，~2天）
   - 对话框输入「跨数×层数、跨度、层高、荷载」→ 脚本化生成框架/桁架/连续梁
   - 比 LLM 更可靠（100% 成功），直接解决"建 5x5 刚框架"类需求
   - 复用 `scripts/gen_frame_5x5.py` 思路做成 GUI 功能
1. **参数扫描动画**（教学价值爆炸，前端即可做，~2天）
   - 拖动滑杆：跨度/荷载/刚度连续变化 → 内力图实时刷新
2. **内力图数值标注**（教学解读刚需，~1天）
   - 曲线上标注关键点：跨中/支座 M 值、反弯点位置、max/min 标签
3. **导出 PDF 报告**（作业场景刚需，~2天）
   - 用现有 SVG 导出 + 简单排版，生成可打印 PDF
4. **标准型钢/材料库**（教学刚需，~1天）
   - 内置 H型钢、C30混凝土等常用数据，学生不用自己查表
5. **CI 测试强化**（工程质量，~0.5天）
   - 把 `compare_femcli_ref.py` / `render_check.mjs` 加入 ci.yml（目前 CI 只跑 ctest）
6. **多工况 + 包络图**（深化分析，~3天）
   - 同一模型多组荷载，显示最不利包络
7. **LLM 分段生成工具**（Agent 深化，~2天）
   - 新增 add_nodes/add_elements 工具，LLM 分小段生成，提升复杂模型成功率
   - 结果自动解读（对比理论公式 qL²/8、5qL⁴/384EI 等，Agent Phase 2）

## 五、不建议短期做的（成本高/收益低）

- 3D 求解（重写核心，建议作为 v2 独立项目）
- 非线性/动力分析（数值稳定性挑战大，教学需求弱）
- 云同步（依赖外部服务，先做单机功能）

## 结论

**当前项目已具备教学软件核心骨架**（建模/求解/可视化/LLM/作业导出）。
下一阶段优先做：**参数扫描动画 → PDF 报告 → 材料型钢库 → 多工况包络图**，
配合 LLM 增强方案（多轮修改 + 结果解读），可形成完整的「结构力学交互实验室」产品。
