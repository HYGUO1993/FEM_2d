# 文档目录说明

为减少仓库根目录杂乱，项目文档已按用途归档到 `docs/`：

- `guides/`：用户使用与教程文档
- `development/`：开发者文档
- `archive/`：历史总结与阶段性报告

常用入口：

- `guides/TUTORIAL.md` — 桌面应用完整教程（推荐从这开始）
- `guides/USAGE_GUIDE.md` — femcli 命令行用法
- `FEM_MODEL_SCHEMA.md` — JSON 模型格式定义
- `LLM_INTEGRATION.md` — LLM 建模助手接口
- `development/DEVELOPMENT.md` — 开发者文档
