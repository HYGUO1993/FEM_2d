# FEM_2d 改进与拓展方案分析

> 在 `MODIFICATION_PLAN.md`（修错）之上，本文件系统分析**拓展方向**：单元库、分析类型、求解器、载荷、前后处理、集成形态、GUI、工程化。每项给出**技术要点 / 依赖 / 工作量 / 价值 / 风险**，最后给出推荐路线。
> 前提：P0~P1 修复（尤其 §1.2 局部坐标端力、§1.3 固端力、§2.1 剖面求解）是多数拓展的地基。

---

## A. 单元库扩展

| 方向 | 技术要点 | 依赖 | 工作量 | 价值 |
|---|---|---|---|---|
| **A1 Timoshenko 梁**（计剪切变形） | 用剪切刚度 GA_s/φ 修正弯曲项，适合深梁/短粗构件 | §1.3 固端力框架 | 1~2 天 | 中：深梁精度显著提升 |
| **A2 杆端释放（铰接/半铰接刚架）** | 单元刚度做静态凝聚（释放端弯矩），输入加释放标志位 | — | 1 天 | **高**：桁架/刚架混合与工程常用 |
| **A3 弹簧/支座刚度单元** | 支座位移改为弹簧约束（Ks 进总刚），天然支持弹性支座 | §2.3 校验 | 0.5~1 天 | 中 |
| **A4 三维杆系（6 DOF/节点）** | 单元刚度 12×12，扭矩/双弯曲，变换矩阵扩到 3D | 结构性改动 | 4~6 天 | 高：从教学到实用 |
| **A5 平面应力/应变膜元 (CPS/CPE)** | CST/Q4 单元，需面积分与高斯点，与杆系并列为"连续体"模块 | 剖面求解(§2.1) 几乎必需 | 5~8 天 | 高：跨入连续体 FEM |
| **A6 板壳元 (DKQ/薄板)** | 弯曲+面内耦合，公式复杂 | §2.1、A5 经验 | 8+ 天 | 中：量大，建议远期 |

**优先**：A2（便宜且常用）→ A4（决定项目上限）→ A5（如要连续体）。

## B. 分析类型扩展

| 方向 | 技术要点 | 依赖 | 工作量 | 价值 |
|---|---|---|---|---|
| **B1 自重/惯性力** | 单元密度×体积组装进载荷向量 | §1.3 | 0.5 天 | 高：工程默认荷载 |
| **B2 屈曲分析（特征值）** | 几何刚度 Kg，解 (K+λKg)φ=0（反幂法/子空间迭代） | §1.2 | 2~3 天 | 高：压杆稳定，教学亮点 |
| **B3 几何非线性（P-Δ/大位移）** | 切线刚度 K_T=K_e+K_σ+K_g，Newton-Raphson/弧长法迭代 | §2.1 + B2 的 Kg | 5~8 天 | 中：二阶效应 |
| **B4 模态分析** | 一致/集中质量矩阵 M，解 Kφ=ω²Mφ | B2 的特征值求解器 | 2~3 天 | 高：动力基础 |
| **B5 瞬态动力（Newmark-β）** | 时程积分，M/C/K，Rayleigh 阻尼 | B4 | 3~5 天 | 中 |
| **B6 谐响应/反应谱** | 频域扫频 / SRSS+CQC 组合 | B4 | 2~4 天 | 中：抗震教学 |
| **B7 移动荷载影响线** | 单位荷载扫过构件，取内力包络 | §1.3 | 1~2 天 | 高：桥梁教学神器 |

**优先**：B1（白菜价）→ B2 或 B7（教学价值最高）→ B4。

## C. 求解器与性能

| 方向 | 技术要点 | 工作量 | 价值 |
|---|---|---|---|
| **C1 剖面(profile) LDLT**（=§2.1） | 直接在 pGK 上分解，O(剖面) | 2~3 天 | **高**：所有大规模前提 |
| **C2 稀疏直接库 (CHOLMOD/SuperLU/MUMPS)** | CSR 组装 + 调库，跨平台 | 2~3 天 | 高：十万级 DOF |
| **C3 迭代求解 PCG** | 共轭梯度 + 对角/SSOR 预条件 | 1~2 天 | 中：特大稀疏 |
| **C4 OpenMP 并行** | 单元装配与矩阵-向量并行 | 1 天 | 中 |
| **C5 节点重排序 (RCM)** | 减小半带宽，直接降剖面长度 | 1 天 | **高**：与 C1 叠加效果显著 |
| **C6 GPU (cuSPARSE/CUDA)** | 迁移求解热点 | 5+ 天 | 低-中：教育项目不建议早做 |

**优先**：C1 → C5（RCM 重排序收益极大且简单）→ 视规模上 C2。

## 推荐路线（三档）

**教学精品档（投入 ~2 周）**
> Phase 0-1（修错+载荷）→ A2 杆端释放 → B1 自重 → B7 影响线 → E1 内力图 → E2 JSON
> 产出：一个**结果正确、功能完整、有弯矩/剪力/轴力图**的杆系教学软件。

**工程可用档（投入 ~1 个月）**
> 加 §2.1 剖面求解 + C5 RCM → B2 屈曲 → B4 模态 → E6 Python 绑定 → E3 计算书
> 产出：可算**数千~万级 DOF**、能出报告、可脚本化的实用工具。

**平台化档（投入 2 月+）**
> A4 三维 / A5 连续体 → B3 几何非线性 → C2 稀疏库 → F4 Web 版
> 产出：接近通用 FEM 平台（慎入，需求驱动）。

**建议先落地"教学精品档"**：以最小投入拿到"正确 + 完整 + 好看"的三重收益，再按真实需求决定是否上工程档。
